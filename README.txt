KANKWE PRIVATE EVENTS - VS CODE EDITION
=======================================

This folder recreates the structure and content of the current Kankwe Private Events website using:
1. index.html
2. style.css
3. script.js
4. images/

The code is deliberately formatted in a simple, readable way for a CTO or junior developer to maintain.

HOW TO RUN
----------
1. Open this folder in VS Code.
2. Open index.html.
3. Install/use Live Server in VS Code if available.
4. Right-click index.html and choose Open with Live Server.

HOW TO REPLACE THE PLACEHOLDER IMAGES
--------------------------------------

IMPORTANT
---------
The page content was recreated from the live Kankwe Private Events page checked on 24 September 2026. The real photos are not copied into this package; image placeholders are used so the owner can upload the correct images.

MAIN EDITING LOCATIONS
----------------------
HTML:
- index.html contains the sections and text.

CSS:
- style.css contains colours, spacing, typography, cards, buttons and responsive layout.
- The main colours are defined at the top under :root.

JAVASCRIPT:
- script.js contains the mobile menu, wellness package cards and WhatsApp enquiry form.
- Edit the wellnessPackages array to change wellness packages.
- Edit whatsappNumber to change the WhatsApp destination.
